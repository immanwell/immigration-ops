# v0.1.0: first route end to end. Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A person with a filled profile gets a tested, source-cited Express Entry (Federal Skilled Worker) assessment from one script, and the `onboard` and `route` modes work on it.

**Architecture:** Route rules live as YAML packs under `routes/`. A deterministic engine under `engine/` turns a profile into facts, evaluates three-valued rules and points grids, and re-runs itself for levers and clocks. Markdown modes call `scripts/assess.mjs` for every number and only explain the JSON it returns.

**Tech Stack:** Node.js 20+, ES modules, JSDoc types, no build step. Dependencies: `yaml`, `ajv`. Tests: `node:test` with `node:assert/strict`, files named `*.test.mjs` next to what they test.

**Spec:** `docs/design/2026-11-15-immigration-ops-design.md`. Read sections 4, 6 and 9 before starting.

**Already in place (Foundation):** `package.json` (`npm test` runs `node --test`), `engine/paths.mjs` with `USER_PATHS` and `SYSTEM_PATHS`, CI (`.github/workflows/ci.yml`), release automation.

## Global Constraints

- **No rule value from memory.** Every threshold, grid line, fee and cut-off in `routes/` is transcribed from the official page open in front of you, with its source and `checked` date. If the page cannot be reached, stop and report. This plan gives no Canadian values on purpose.
- Engine modules do no I/O (`engine/pack.mjs` is the only one that reads files). They must run unchanged in a browser later.
- Rule evaluation is three-valued: `met`, `not_met`, `unknown`. A missing fact is `unknown`, never `not_met`.
- Fact states are exactly `verified`, `assumed`, `planned`, `missing`. A derived fact takes the weakest state of its inputs, in the order `missing` < `planned` < `assumed` < `verified`.
- Dates are ISO strings (`YYYY-MM-DD`) everywhere in data and results. Parse them explicitly; never rely on YAML date coercion.
- Every user-layer path stays git-ignored (`engine/paths.mjs`). Fixtures and examples use fictional personas only.
- Public prose: no em dashes, plain sentences, and the information-not-advice line in every report.
- Conventional commits. Rule data uses the `data` type, for example `data(ca/express-entry-fsw): add selection grid`.
- One branch and one pull request per task. Never commit to `main`. Never `git add -A`.

## Review Focus

1. A profile with a whole section absent (no `languages`, no `experience`) returns `unknown` results that name the missing facts. It never throws.
2. A language test older than the route's validity window is treated as missing, with the reason `expired`, at the `asOf` date being evaluated (so clocks show it expiring).
3. Age on a birthday boundary and a 29 February birth date are computed correctly for any `asOf`.
4. A wrongly typed profile value (`"7"` for a score, a number for a date) is rejected by profile validation with the field path, not compared silently.
5. A pack past its `review_by` date still evaluates, and the result carries `pack.overdue: true`, which the `route` mode must print.

Each line has a test in the task that owns the code (Tasks 1, 8, 1, 10 and 5).

## Shared Types

```js
/** @typedef {'verified'|'assumed'|'planned'|'missing'} FactState */
/** @typedef {{ value: any, state: FactState, reason?: string }} Fact */
/** @typedef {Map<string, Fact>} Facts                     keys are dotted paths */
/** @typedef {'met'|'not_met'|'unknown'} Status */
/** @typedef {{ status: Status, assumed: boolean, missing: string[] }} RuleResult */
/** @typedef {{ id: string, label: string, points: number, max: number|null,
 *             assumed: boolean, missing: string[], source: string|null }} PointsLine */
/** @typedef {{ id: string, total: number, max: number|null, assumed: boolean,
 *             lines: PointsLine[] }} PointsResult */
/** @typedef {{ route: object, grids: Record<string, object>, country: object,
 *             shared: Record<string, object>, resolvers: Function[], dir: string }} Pack */
/** @typedef {{ route: string, as_of: string,
 *   pack: { verified: string, review_by: string, overdue: boolean },
 *   eligibility: { status: Status, assumed: boolean,
 *     requirements: Array<{ id: string, label: string, source: string } & RuleResult> },
 *   points: Record<string, PointsResult>,
 *   competitiveness: null | { grid: string, score: number,
 *     draws: Array<{ date: string, category: string, cutoff: number, margin: number }> }
 * }} RouteResult */
```

### Task 1: Facts

**Files:** Create `engine/facts.mjs`, `engine/facts.test.mjs`.

**Interfaces:**
- Produces:
  - `ageOn(dateOfBirth: string, asOf: string): number`
  - `buildFacts(profile: object, opts: { asOf: string }): Facts`
  - `getFact(facts: Facts, path: string): Fact` (absent path returns `{ value: undefined, state: 'missing' }`)
  - `withOverrides(facts: Facts, overrides: Record<string, any>, state?: FactState): Facts` (returns a new map, default state `assumed`)

Education with a `completed` date after `asOf` is not counted.

### Task 2: Rules

**Files:** Create `engine/rules.mjs`, `engine/rules.test.mjs`.

**Interfaces:**
- Consumes: `getFact` (Task 1).
- Produces: `evaluateRule(rule: object, ctx: { facts: Facts, scoreGrid?: (gridId: string) => PointsResult }): RuleResult`
- Grammar: `{ all: Rule[] }`, `{ any: Rule[] }`, `{ not: Rule }`, `{ fact, op, value }`, `{ points: gridId, op, value }`. Operators: `eq ne gt gte lt lte in exists`. An unknown operator or rule shape throws `Error` naming it.
- Logic: `all` is `not_met` if any child is `not_met`, else `unknown` if any is `unknown`, else `met`. `any` is `met` if any child is `met`, else `unknown` if any is `unknown`, else `not_met`. `not` swaps `met` and `not_met` and keeps `unknown`. `assumed` is true when any fact that was read has state `assumed` or `planned`. `missing` lists the paths of missing facts, without duplicates.

- [ ] **Step 1: Write the failing tests** with facts `a = 5 verified`, `b = 7 assumed`, `c` missing:

```js
const ctx = { facts };
assert.deepEqual(evaluateRule({ fact: 'a', op: 'gte', value: 5 }, ctx), { status: 'met', assumed: false, missing: [] });
assert.deepEqual(evaluateRule({ fact: 'b', op: 'gte', value: 7 }, ctx), { status: 'met', assumed: true, missing: [] });
assert.deepEqual(evaluateRule({ fact: 'c', op: 'gte', value: 1 }, ctx), { status: 'unknown', assumed: false, missing: ['c'] });
assert.equal(evaluateRule({ all: [{ fact: 'a', op: 'gte', value: 5 }, { fact: 'c', op: 'gte', value: 1 }] }, ctx).status, 'unknown');
assert.equal(evaluateRule({ all: [{ fact: 'a', op: 'gte', value: 6 }, { fact: 'c', op: 'gte', value: 1 }] }, ctx).status, 'not_met');
assert.equal(evaluateRule({ any: [{ fact: 'a', op: 'gte', value: 6 }, { fact: 'c', op: 'gte', value: 1 }] }, ctx).status, 'unknown');
assert.equal(evaluateRule({ any: [{ fact: 'a', op: 'gte', value: 5 }, { fact: 'c', op: 'gte', value: 1 }] }, ctx).status, 'met');
assert.equal(evaluateRule({ not: { fact: 'c', op: 'exists' } }, ctx).status, 'met'); // exists on a missing fact is not_met, never unknown
assert.equal(evaluateRule({ fact: 'a', op: 'in', value: [1, 5] }, ctx).status, 'met');
assert.throws(() => evaluateRule({ fact: 'a', op: 'approx', value: 5 }, ctx), /approx/);
// points rule
const c2 = { facts, scoreGrid: () => ({ id: 'g', total: 60, max: 100, assumed: true, lines: [] }) };
assert.deepEqual(evaluateRule({ points: 'g', op: 'gte', value: 50 }, c2), { status: 'met', assumed: true, missing: [] });
```

A points rule whose grid has lines with missing facts is `unknown` when the total is below the value (more points might still arrive) and `met` when the total already reaches it. Add one test for each.

### Task 3: Points

**Files:** Create `engine/points.mjs`, `engine/points.test.mjs`, `engine/testdata/routes/zz/toy/points.yml` (content above).

**Interfaces:**
- Consumes: `getFact`, `evaluateRule` (for `when`).
- Produces: `scoreGrid(grid: object, gridId: string, facts: Facts): PointsResult`
- Factor kinds: `bands` (numeric `input`, or `inputs: string[]` summed), `lookup`, `matrix`, `group` (child factors summed, then limited by `cap`). Any factor may carry `when` (a rule); a factor whose `when` is `not_met` scores 0 and is left out of `lines`, and one whose `when` is `unknown` scores 0 and reports the missing paths. A missing input scores `default` and is listed in the line's `missing`. A group produces one line for the group (after the cap) with its children nested under `children`. `total` is never above `grid.max`.

### Task 5: Route evaluation

**Files:** Create `engine/evaluate.mjs`, `engine/evaluate.test.mjs`.

**Interfaces:**
- Consumes: Tasks 1 to 4.
- Produces: `evaluateRoute(pack: Pack, profile: object, opts: { asOf: string, today?: string, overrides?: Record<string, any> }): RouteResult`
- Order: `buildFacts`, then each resolver, then `withOverrides`, then requirements and grids. `eligibility.status` is the `all` of the requirements. `pack.overdue` is `today > review_by` (`today` defaults to the real date, not `asOf`). `competitiveness` is filled when the route declares `competitiveness: { kind: draw-cutoffs, grid, draws }` and `shared[draws]` exists: the newest three draws per category with `margin = score - cutoff`.

### Task 6: Levers and clocks

**Files:** Create `engine/levers.mjs`, `engine/clocks.mjs`, and a test file for each.

**Interfaces:**
- Consumes: `evaluateRoute`.
- Produces:
  - `runLevers(pack, profile, opts: { asOf, today? }): Array<{ id, label, eligibility: { before: Status, after: Status }, points: Record<string, { before: number, after: number, delta: number }> }>`
  - `runClocks(pack, profile, opts: { asOf, today?, months?: number[] }): Array<{ as_of: string, reason: string, eligibility: Status, points: Record<string, { total: number, delta: number }> }>`
